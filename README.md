# Team20
ToDo Calendar website, where you can keep up with your daily tasks. 
This project is a full-stack web application built with Node.js, Express, and MongoDB. The app includes:

- A calendar for adding and managing events

- A to-do list with task prioritization

- Weather data fetched from an open API

- Latest news headlines fetched via API

- Daily affirmation quotes

- A goal tracker that counts down the days towards a personal goal

The project focuses on backend development. It includes creating a REST API with basic CRUD operations, using external APIs, and building a clear server structure. The frontend is simple and focuses on easy use and accessibility.

Additional project management includes:

Kanban board for task tracking

Scrum meeting notes

Version control with GitHub
